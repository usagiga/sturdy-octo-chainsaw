# Spec Delta

## Purpose

ビルド時に記事一覧ページと各記事詳細ページを静的HTMLとして出力し、サーバーを常時稼働させずに配信できるようにする。

## ADDED Requirements

### Requirement: 公開ルートの静的出力
ビルドはすべての公開対象記事の詳細ページと一覧ページを静的HTMLとして出力しなければならない(SHALL)。

#### Scenario: ビルド後の記事ページ出力
- **WHEN** 公開対象記事が存在する状態でビルドが実行される
- **THEN** ビルド成果物にはその記事の詳細ページに対応する静的HTMLファイルが含まれる

#### Scenario: ビルド後の一覧ページ出力
- **WHEN** ビルドが実行される
- **THEN** ビルド成果物には一覧ページに対応する静的HTMLファイルが含まれる

### Requirement: 下書きルートの出力除外
ビルドは `draft: true` の記事に対応するページを静的出力に含めてはならない(SHALL NOT)。

#### Scenario: draft記事のビルド除外
- **WHEN** `draft: true` を持つ記事が存在する状態でビルドが実行される
- **THEN** ビルド成果物にはその記事に対応する静的HTMLファイルが含まれない
