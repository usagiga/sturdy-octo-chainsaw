# Spec Delta

## Purpose

個々の記事を閲覧するための詳細ページを提供し、記事本文と付随するメタデータを表示する。

## ADDED Requirements

### Requirement: 記事詳細ページの表示
システムは各公開記事について、そのスラッグに対応するURL（`/blog/<slug>`）で記事本文をレンダリングしなければならない(SHALL)。

#### Scenario: 存在する記事の閲覧
- **WHEN** ユーザーが公開済み記事のスラッグに対応するURLにアクセスする
- **THEN** その記事のMDX本文がレンダリングされて表示される

### Requirement: 記事メタデータの表示
記事詳細ページはタイトル・日付・タグ（存在する場合）を本文とともに表示しなければならない(SHALL)。

#### Scenario: タグ付き記事の表示
- **WHEN** `tags` を持つ記事の詳細ページが表示される
- **THEN** そのページにはタイトル・日付に加えてタグが表示される

#### Scenario: タグなし記事の表示
- **WHEN** `tags` を持たない記事の詳細ページが表示される
- **THEN** タグは表示されない

### Requirement: 存在しない記事への404応答
システムは、公開対象の記事に存在しないスラッグへのアクセスに対して404を返さなければならない(SHALL)。

#### Scenario: 未知のスラッグへのアクセス
- **WHEN** ユーザーが公開済み記事のいずれのスラッグにも一致しないURLにアクセスする
- **THEN** 404が返される

#### Scenario: draft記事のスラッグへのアクセス
- **WHEN** ユーザーが `draft: true` の記事のスラッグに対応するURLにアクセスする
- **THEN** 404が返される
